# BvN web lobby

Static lobby page that hosts the Flash game in Ruffle and talks to the relay (see `tools/relay/PROTOCOL.md`).

- `config.js`: `RELAY_WS_BASE` is derived automatically: `?relay=wss://host` override, else `ws://localhost:8080` on localhost, else `config.prod.js` (generated by `tools/deploy/build-web.mjs`; the committed copy is an empty stub). Also `SWF_URL`, `RUFFLE_URL` (pinned `@ruffle-rs/ruffle@0.7.1`, or the self-hosted copy from `config.prod.js`).
- Deployment: see `tools/deploy/README.md`. `_headers` is for Cloudflare Pages / Netlify.
- Local test: start the relay, then `node web/dev-server.mjs --assets <dir containing bvn.swf and game assets>` and open http://localhost:5173.
- Invite link is the current page URL.
- Controls hint text is a placeholder in `index.html`.
